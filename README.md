# Teams Status Keeper

Keeps your Mac awake and nudges the cursor 1px on an interval so idle timers don't trip.

1. `python3 server.py`
2. Open http://localhost:8765 (or the hosted UI, which talks to the helper on your Mac)
3. First run: allow your Terminal in System Settings → Privacy & Security → Accessibility

macOS only. The hosted page is only a control panel; the helper must run locally.
Note: using this may violate your employer's policies.
